# Playtest notes template

Copy this to `docs/playtests/YYYY-MM-DD.md` after every headset session. Short, messy notes are fine. Claude turns them into fixes.

```
# Playtest YYYY-MM-DD, milestone Mx

Who played: (how many, rough ages, first time or not)
Build: (commit or APK name)
Matches played:

## Best moment
(The thing someone would clip or retell.)

## Scariest moment / when people went quiet

## Where people got confused
(What did someone have to ask about? Kids especially.)

## Bugs
- (what happened, where, and a screenshot or video if you have one)

## Felt bad / boring
(Vague is fine: "too easy", "nobody found the Host", "stage 2 dragged".)

## Did they want to play again? (yes / no / "one more")

## Fix first
1.
2.
3.
```

Then tell Claude: *"Read docs/playtests/YYYY-MM-DD.md, run scare-director and kid-check on it, and fix the top three."*
